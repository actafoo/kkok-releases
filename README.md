# 콕! 설치 파일

전자칠판 상주형 학급 체크 위젯 **콕!** 의 Windows 설치 파일과 자동 업데이트 정보를 두는 곳입니다.
코드는 이곳에 없습니다.

- 최신 버전 내려받기: [Releases](https://github.com/actafoo/kkok-releases/releases/latest) → `콕!_버전_x64-setup.exe`
- 설치된 콕!은 켤 때 이곳의 `latest.json`을 보고 새 버전이 있으면 스스로 업데이트합니다.
  주고받는 것은 버전 정보뿐이며, 학생 이름·기록 등 어떤 정보도 보내지 않습니다.
